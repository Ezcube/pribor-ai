# Сопроводительное сообщение

Направляю тестовое задание: https://github.com/Ezcube/pribor-ai

Прототип на Python принимает JSON и через бесплатную модель OpenRouter формирует черновик карточки: SEO-заголовок и описание, характеристики, поисковые запросы и блок для менеджера. Результат сохраняется в JSON и Markdown; примеры подготовлены для testo 510 и testo 830-T1.

Ключевое решение — модель выбирает и упорядочивает исходные факты, а программа проверяет план и переносит значения без изменений. Пропуски отмечаются как «данных нет», ошибки ввода и API обрабатываются, платные модели заблокированы.

Основные сложности: в фиде не было технических описаний, поэтому данные дополнены по страницам товаров с сохранением источников; один ответ бесплатной модели был обрезан, что потребовало увеличить лимит генерации. Пройдены 55 тестов и реальные вызовы API для двух карточек с нулевой стоимостью. Инструкция, ограничения и скриншоты включены в репозиторий.
