# Проверка прототипа

Дата: **3 ноября 2026 года**.

## Автоматические проверки

`python -m unittest discover -s tests` — **55 тестов, все прошли**.

- 23 проверки входов, плана модели, сохранности фактов, пропусков и ограничений результата.
- 8 проверок CLI, файлов, конфигурации и сохранности предыдущего результата при сбое.
- 24 проверки API-клиента: бесплатные модели, нулевые ограничения цены, ошибки/повторы, JSON Schema, неполные ответы и защита секретов.

Тесты выполнялись без сети на имитированном транспорте. Отдельно выполнены настоящие запросы, описанные ниже.

## Настоящий OpenRouter API

Команда:

```powershell
python -m pribor_ai examples/products.json --output examples/cards.live.json --markdown examples/cards.live.md
```

Запрошенный маршрут: `openrouter/free`. В обоих успешных ответах фактическая модель — `nvidia/nemotron-3.5-super-vl:free`.

| Проверка | testo 510 | testo 830-T1 |
|---|---:|---:|
| Символов в SEO-заголовке | 35 | 21 |
| Символов в итоговом SEO-описании | 938 | 897 |
| Поисковых запросов | 5 | 5 |
| Входных токенов, по API | 2 158 | 2 127 |
| Выходных токенов, по API | 3 014 | 3 404 |
| `usage.cost`, по API | 0 | 0 |

Идентификаторы запросов, время, фактическая модель, токены, стоимость и оригинальные планы сохранены в [examples/cards.live.json](examples/cards.live.json). Читаемые карточки: [examples/cards.live.md](examples/cards.live.md). Стоимость в таблице относится к этим двум успешным ответам, а не к истории аккаунта.

Оба результата имеют статус `needs_data`: у манометра уточняются интерфейсы и гарантия, у пирометра — степень защиты и интерфейсы. Это осознанные пропуски исходных данных, а не ошибка генерации. Полная погрешность, включая интервалы и условия, сохранена без сокращений.

При первом прогоне с общим лимитом ответа 4096 токенов один ответ был обрезан. Клиент отклонил его и не сохранил частичный пакет. Лимит увеличен до 8192: бесплатные модели могут тратить общий бюджет на рассуждения. Повторный пакет успешно завершён. Платных моделей или платного переключения нет.

После чтения результатов исправлена локальная сборка: резервные факты больше не добавляются, если выбранного моделью текста уже достаточно для минимума 800 символов. Это устранило повтор типа прибора в конце описаний. Итоговые карточки пересобраны из **тех же настоящих API-планов**, без дополнительного вызова; это отмечено `reused_api_plan=true`, исходное время вызова — `api_completed_at`. После изменения прошли все 55 тестов.

## Границы подтверждения

Проверено, что отображаемые характеристики и фрагменты SEO-текста совпадают с входными данными. Описания визуально прочитаны; таблицы характеристик сверены с исходными значениями. Истинность данных магазина, применимость прибора к конкретному объекту и последующая доступность бесплатной модели не гарантируются этими тестами.

Ключ хранится только в локальном `.env`, исключённом из Git и передаваемого архива. В проекте нет публичного деплоя, базы данных или CMS. Репозиторий для передачи: [Ezcube/pribor-ai](https://github.com/Ezcube/pribor-ai).
